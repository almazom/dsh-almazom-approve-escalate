# TC-004 — Publish: GitHub repo + dsh-plugin topic + catalog PR + Show Your Plugins

## User Story

As the operator, I want publish: GitHub repo + dsh-plugin topic + catalog PR + Show Your Plugins, so that the plugin delivers real value end-to-end and can be published with evidence.

## Story Points

3

## Dependencies

TC-003

## Description

As the operator, I want the plugin published where the DSH ecosystem actually looks, so that it is discoverable and installable by anyone.

Files:
- `README.md`
- `docs/install.md`

## Implementation Steps

1. `git init` + initial commit; create GitHub repo `almazom/dsh-almazom-approve-escalate` (public, description one-liner, topics: `dsh-plugin`, `deepseek-harness`); push.
2. npm publish if `npm whoami` succeeds; otherwise `docs/install.md` documents `dsh plugin --profile web add git+https://github.com/almazom/dsh-almazom-approve-escalate.git` (pnpm forwarder accepts git specs) + rollback (`dsh plugin ... remove`).
3. README (EN, concise): what it does (one click = approve + escalate), screenshot/GIF, install, config keys (`preset`, `label` via profile patch row `config:`), security/trust section (full host privileges doctrine; the button only composes two manual actions; no telemetry; no secrets), compatibility (0.1.5-rc.x, peer range), provenance (built from this repo, no model round in tests except TC-003's single approval trigger).
4. Post to upstream discussion category "Show Your Plugins!" (deepseek-ai/deepseek-harness) — same voice as discussion #6616: what/why/how, install one-liner, link.
5. Submit to the catalog: fork `awesome-dsh-plugin/awesome-dsh-plugin`, add entry to `plugins.json` ({name, owner, url, category: ui or tools, description en, npm/git install, screenshots}), PR per contributing.md checklist.

## Acceptance Criteria
- `gh repo view almazom/dsh-almazom-approve-escalate --json url,repositoryTopics` shows the repo with `dsh-plugin` topic.
- README contains install + rollback + security sections (grep-able headings).
- Show Your Plugins post URL recorded; catalog PR URL recorded (or exact blocker documented).
